Standardized patterns governing modern tool calling, review cycles, and multi-agent systems.

PROTOCOL: MODEL CONTEXT PROTOCOL (MCP) JSON-RPC 2.0

Eliminates proprietary tool wrappers. Standardizes how an AI Host process discovers and accesses tools, file systems, and enterprise data via explicit protocol boundaries.

[ Host Environment / Agent Runtime ]
↓ tools/list — Dynamic capability discovery
↓ resources/read — Contextual data ingestion
↓ tools/call — Guardrailed execution
[ MCP Server Instances ] (Files, DBs, GitHub, APIs)
PIPELINE: CODERABBIT AUTONOMOUS SWE LOOP SELF-HEALING

Devin / SWE-bench pattern: The coding agent generates initial edits, executes coderabbit review --agent to parse machine-readable NDJSON, and auto-applies targeted patches before submitting a PR.

1. Agent implements target feature branch
2. CLI Review: coderabbit review --agent --uncommitted
3. Ingest NDJSON: Filter Critical (RCE/eval) & Major errors
4. Apply automated remediation + AST syntax verify
5. Clean verification & automated PR merge ready
