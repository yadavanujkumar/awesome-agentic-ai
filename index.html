SPECIFICATION: MODEL CONTEXT PROTOCOL (MCP) 2026 STANDARD

Open Standard for Tool & Data Discovery

MCP establishes an open JSON-RPC 2.0 contract between host AI apps and sandboxed execution servers. Replaces fragile bespoke tool wrappers with universal capability negotiation.

[Host Agent] ↔ JSON-RPC 2.0
• tools/list (Discover schemas)
• resources/read (Extract prompt context)
• tools/call (Execute safely in sandbox)
→ [MCP Server] (Postgres, Files, GitHub, Jira)
