🔌 Model Context Protocol (MCP) Architecture

2026 Standard

Standardizes how LLM agents discover tools, inspect databases, and query SaaS resources without hardcoded integrations.

[Host Agent] ← (JSON-RPC 2.0 / stdio / SSE) → [MCP Client]
• Tool Discovery: tools/list
• Resource Retrieval: resources/read
• Safe Execution: tools/call (with user guardrail)
→ [MCP Servers] (PostgreSQL, Filesystem, GitHub, Jira, Memory)

🐇 Autonomous SWE Code Review Loop

Self-Healing

Devin/SWE-bench pattern: Coding agent generates patch → CodeRabbit CLI review emits NDJSON → agent prioritizes critical issues & auto-heals.

Step 1: Agent implements requested feature branch
Step 2: coderabbit review --agent --uncommitted (NDJSON stream)
Step 3: Filter Critical (RCE/eval, SQLi) & Major (Exceptions)
Step 4: Autonomous patch application & AST syntax verify
Step 5: Clean re-review & PR ready for merging
